# Harun Or Rashid Rasel — Personal Portfolio

A responsive personal portfolio built with HTML, CSS, Tailwind CSS (CDN), and vanilla JavaScript.

## Sections
- Navbar with responsive mobile menu
- Hero / Introduction
- About Me
- Technical Skills
- Projects
- Education
- Contact section with a contact form
- Footer

## Technologies
HTML5, CSS3, Tailwind CSS CDN, Vanilla JavaScript.

## Run locally
1. Download or clone this repository.
2. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.
3. Open `index.html` in a browser. For best results, use the VS Code Live Server extension.

## Contact form
The contact form is a visual-only design for the assignment. It does not submit messages. Visitors can contact the portfolio owner directly at `harunorrashid289@gmail.com`.
